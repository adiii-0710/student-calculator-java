# Student Calculator

A simple Java program that displays a student profile and performs basic arithmetic operations using two numbers.

## Features

- Displays student information
- Stores student details using variables
- Performs basic arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Demonstrates Java variables and data types
- Uses type casting for decimal division

## Technologies Used

- Java

## Student Details

- Name: Rahul Sharma
- Roll No: 101
- Course: B.Tech Computer Engineering
- Year: Second Year

## Calculator Values

- First Number: 25
- Second Number: 10

## Operations

The program calculates:

```text
Addition       : 35
Subtraction    : 15
Multiplication : 250
Division       : 2.5
```
How to Run
Make sure Java is installed on your system.
Clone the repository.
Open the project in VS Code or any Java-supported IDE.
Compile the program:
javac StudentCalculator.java
Run the program:
java StudentCalculator
Output
